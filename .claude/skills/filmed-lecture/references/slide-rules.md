# 촬영강의 슬라이드 규칙 (v1.6)

## 성격

촬영강의 슬라이드는 **설명의 중심**이다. 판서슬라이드보다 설명 밀도가 높아도 된다 — 글자, 도형, 이미지, 코드 강조가 들어갈 수 있다. 동시에 **판서 엔진 위에서 동작**하므로 유사시(추가 질문 대비 리허설, 촬영 중 즉석 보충) 판서모드 버튼으로 빈 칠판을 열거나 슬라이드 위에 펜 판서를 할 수 있다.

## 판서 엔진 기반 조립 (v1.6 핵심)

- 촬영강의 슬라이드 = **panseo-slide 스킬의 `rich` 프로파일** (v1.7 — 프로파일 정의·템플릿 소유·재동기화 절차는 `.claude/skills/panseo-slide/SKILL.md`의 "하네스 통합 재정의"가 원천).
- 조립 원본: `.claude/skills/panseo-slide/template/board_template_light.html` (라이트 판서 엔진 — panseo-slide 스킬 소유로 이관됨).
- 조립 방법은 panseo-slide와 동일: 템플릿 복사 → `STEPS START ~ STEPS END` 사이를 슬라이드 `<section class="step">`으로 교체 → `{{DECK_TITLE}}` 치환 → 첫 섹션만 `active`.
- 엔진 `<script>` 수정 금지. 슬라이드 콘텐츠 전용 CSS는 STEPS 영역 내 scoped `<style>`로만 추가한다 (엔진 스타일과 충돌 금지).
- **내용 밀도는 촬영 기준이다** — 기본 판서슬라이드처럼 "컷당 한 줄"로 비우면 안 된다. 스토리보드가 정한 메시지·구성 요소를 그대로 담되 max_slide_words를 지킨다.
- 판서 기능이 살아 있는지 조립 후 확인: 펜 판서, `b`(판서모드/빈 칠판), `g`(모눈), `⛶` 전체화면, ←/→ 네비.

## 테마·일관성 (v1.6)

- **라이트 테마 고정.** 배경 밝은 색 + 어두운 텍스트. Manifest `style.visual_style`이 명시적으로 다크를 요구할 때만 예외.
- **덱 간 디자인 일관성.** 한 강의의 모든 레슨 덱(레슨 모드 무관)은 같은 템플릿·같은 색 토큰·같은 타이포 스케일을 쓴다. 특정 레슨이 다른 화면(시뮬레이터·IDE)의 팔레트를 계승하지 않는다 — 시뮬레이터는 별도 창의 별도 산출물이고, 슬라이드는 슬라이드끼리 일관돼야 한다.
- cue 슬라이드(SIM 실행/종료 등)도 같은 덱 스타일 안에서 표현한다. [실행 파일/조작 요약/화면 전환] 3필드 규칙은 유지.
- 시뮬레이터(edu-sim-builder)는 다크 테마 유지 — 별도 창 전환이라 슬라이드 라이트와 충돌하지 않는다.

## 불변 규칙 (기존 유지)

- 한 슬라이드 = 하나의 핵심 메시지. 메시지가 2개면 나눈다.
- 슬라이드당 단어 수 ≤ `constraints.max_slide_words` (기본 45). **카운트 규칙**: 출처 각주, 시드 도형(d2 승계 SVG) 내부의 식별자·노드·엣지 라벨, 가운뎃점 복합토큰(1어절 취급)은 제외 — 본문 메시지 어절만 센다 (QA v2 방법 확정).
- 코드 폰트 ≥ `constraints.code_font_min_pt` (기본 22pt) — 보조 칩·배지 포함 전부.
- 긴 코드 전체 금지 — 핵심 변경점만 (diff는 IDE 화면 담당).
- 시뮬레이터 내장 금지 — cue 슬라이드로만.
- 원고에 없는 내용 추가 금지 (스토리보드가 계약). 도형은 원고의 `d2` 시드를 우선 소비한다.

## 제작 단계 분해 (기존 유지)

```text
1. slide-storyboard-agent: 슬라이드별 [메시지/구성 요소 명세(원고 d2·IMG 시드 참조)/cue 여부] → [G4 승인]
2. 요소 명세 구체화 (_workspace)
3. slide-composer-agent: 엔진 템플릿 복사 + STEPS 조립
4. qa-agent 렌더링 QA: 단어 수, 폰트, 한 슬라이드 한 메시지, node --check, 판서 기능 동작
```

## 기술 요건

- 산출물 = 엔진 기반 단일 HTML (`courses/{id}/slides/L0x.html`). 외부 의존은 폰트 CDN까지만.
- 슬라이드 1장 = 1개 `.step` 섹션 (PPTX 변환 대비 구조 유지 — 후속 과제).
- 다이어그램은 인라인 SVG. 색은 라이트 토큰 기준으로.

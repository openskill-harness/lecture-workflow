# 온라인(유튜브 판서 VOD) 원고·시청 규칙 (v1.7 개편)

온라인 강의는 **유튜브 녹화 판서 강의**다: 강사가 summary 슬라이드 위에 무조건 판서하며 진행하고, 시청자는 영상으로 본다. 현장 질문이 불가능하므로 자료 자체가 hook과 회수를 책임져야 한다는 원칙은 유지된다.

**판서 전제 (v1.7):** `visual` 필드는 "강사가 판서로 그릴 것"의 명세다 (완성 도형을 슬라이드에 싣는 게 아니라 여백에 그린다). `interaction` 필드의 시뮬레이터는 영상 속에서 강사가 조작 시연하고, 영상 설명란에 시뮬 링크를 제공해 시청자가 따라 눌러볼 수 있게 한다.

## 원고 섹션 구조 (필수)

모든 섹션은 다음 필드를 갖춘다 (스키마: `lecture-harness`의 `references/schemas.md` 7절):

| 필드 | 역할 | 규칙 |
|------|------|------|
| `learning_goal` | 이 섹션에서 얻는 것 | Manifest learning_goals와 연결 |
| `hook` | 시작 질문/문제 상황 | 정의로 시작 금지. 질문 또는 곤란한 상황으로 |
| `concept` | 핵심 개념 | hook에 답하는 순서로. 개념 나열 금지 |
| `visual` | 강사가 판서로 그릴 것 (컷과 1:1 대응) | 완성 도형이 아니라 "그리는 순서"로 명세 |
| `interaction` | 시뮬레이터 cue (해당 시) | 강사 시연 순서 + "시청자는 링크에서 무엇을 눌러 무엇을 관찰하라"까지 지시 |
| `summary` | 한 줄 회수 | hook의 질문에 답이 되었는지 자가 검사 |

## 흐름 검사 (qa-agent 기준)

- hook → concept → summary가 **하나의 질문-답 사슬**로 이어지는가. summary가 hook과 무관하면 실패.
- 섹션 간에도 사슬이 이어지는가 (이전 summary → 다음 hook 연결).
- interaction cue가 가리키는 시뮬레이터가 실존하고, 지시한 조작이 실제로 가능한가.

## 시뮬레이터 자기주도 장치 (online_self_paced 프로파일 — 유지)

시뮬레이터는 영상 내 시연 + **시청자 배포 겸용**이므로 자기주도 장치를 유지한다:
- 처음 열었을 때 무엇을 해야 하는지 안내 문구가 보이는가
- 리셋 버튼이 있는가 (막다른 상태에서 혼자 복구)
- 단계 진행 표시가 있는가 (어디까지 봤는지)

## 분량

- 한 레슨 = 한 개념 덩어리. 학습자 집중 단위(10~20분 분량)를 넘기면 레슨 분할을 G2에서 제안한다.
- 판서슬라이드 규칙은 오프라인과 동일 (글자 적게, 여백) — `panseo-slide` 스킬 참조.

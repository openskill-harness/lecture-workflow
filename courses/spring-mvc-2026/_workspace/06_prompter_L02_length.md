## 2. SIMULATION 페이싱 특례 — 실효 발화 기준 분리 산정

지시에 따라 "무성 구간(배치 클릭, 화면 관찰 대기)"을 제외한 **실효 발화 시간** 기준으로 별도 산정.

### 2-1. 무성 구간(발화 없는 벽시계 시간) 추정
| 구간 | 성격 | 추정 |
|---|---|---|
| `[SIM 실행]` 로드 + 모드 A 확인 | 조작 | ~6초 |
| 모드 A STEP 0~10 전환·애니메이션 관찰 비트 (11회 × ~2초) | 관찰 | ~22초 |
| `[SIM 리셋 → 모드 ②]` 전환 | 조작 | ~5초 |
| **모드 B STEP 0~6 연속 클릭 "나레이션 없이 빠르게"** (명시적 무성) | 조작+관찰 | ~12초 |
| 모드 B STEP 7~12 전환·관찰 비트 (6회 × ~2초) | 관찰 | ~12초 |
| `[SIM 종료]` | 조작 | ~2초 |
| **무성 합계** | | **≈ 59초 ≈ 1.0분** |

### 2-2. 실효 발화 예산 → 판정
- 실효 발화 예산 = 7.0분 − 1.0분(무성) = **약 6.0분**
- 6.0분 발화 대역(250~300자/분) = **1,500 ~ 1,800자**
- 초안 2,913자 vs 실효 상한 1,800자 → **+1,113자 / +62%**

### 2-3. 특례가 완화가 아니라 악화인 이유 (결론)
- 무성 구간은 벽시계 7분 **안에서** 발화 시간을 **깎아낸다.** 따라서 SIMULATION은 발화 예산을 **줄인다.**
- 즉 하네스 기준(1,750~2,100)보다 실효 기준(1,500~1,800)이 **더 빡빡**하다. 초과 규모는 특례로 **더 커진다**(+39% → +62%).
- **결론: SIMULATION 페이싱 특례를 "초과 면제"로 인정할 근거는 없다.** 클릭/관찰은 시간을 벌어주지 않는다.
- 단, SIMULATION 설계 원리("무엇이 보이는가는 화면이 말한다", 원고 ref 0 주석)는 **다른 방향의 여지**를 준다 — 화면과 중복되는 "무엇이 보이는가" 서술은 삭제해도 학습 손실이 없다. 아래 조정 후보의 근거는 특례가 아니라 **이 시각 중복성**이다.

## 5. 진단 — 프롬프터 트림이 아니라 원고 스코프 문제

- Tier 1 전부 반영해도 **약 2,706자** → 하네스 상한(2,100) **+29%**, 실효 상한(1,800) **+50%**. **여전히 구조적 초과.**
- 원고(인용 제외 2,834자 ≈ 10.3분 @275)는 7분 슬롯의 **약 1.5배**. 초과분은 방백 제거로 흡수 불가.
- **임의 삭제 금지 원칙**에 따라 초안은 원고 충실 변환 상태로 둠. 어느 관문 서사를 줄일지 **내용 결정은 원고 작성자/사용자**.

| 기준 | 대역 | 초안 | 초과 | 판정 |

**권고**
1. **SIMULATION 페이싱 특례 = 불인정.** 무성 구간은 발화 예산을 늘리지 않고 줄인다. 특례로 초과가 정당화되지 않는다.
2. Tier 1(A~E) 반영: 2,913 → ~2,706자. **필요하지만 불충분**(여전히 +29%).
3. 상한 도달하려면 추가 **~600자** 절감 필요 → 프롬프터 트림으로는 불가. **원고 L02를 7분 스코프로 개정** 필요(관문 서사 밀도 축소: 예 — 모드 A STEP 1~5의 "왜" 설명을 압축하거나, 정리 SLIDE 02 회고를 대조 한 문장으로 압축). **클라이맥스(STEP 8-A/9-A/8-B) 유지 전제.**
4. 대안: 편성상 가능하면 L02 duration 재검토(단 total 30분 고정 → 타 레슨 연쇄 영향, 오케스트레이터 판단).
5. 원고 개정 확정 시 **해당 구간만 재변환 후 전체 길이 검증 재수행**(재호출 지침).

# 제안서: 자산 임베드 "안전 여백(fit-in-box)" 규약

- 날짜: 2026-07-06
- 상태: codex 사전검증 대기 → 승인 후 반영
- 계기: 사용자 요청("D2가 ppt/html/스토리보드에 들어갈 때 화면을 꽉 채우지 말고 여백을 남겨라") + 실제 오버플로 버그 발견

## 1. 배경 — 현재 문제 (증거)

시각자산(D2·이미지)이 소비 산출물에 임베드될 때 **여백 규칙이 없다.**

1. **PPTX 오버플로(실제 버그)**: `build_pptx.py`가 이미지에 **너비만** 지정(`add_picture(..., width=4.5")`)하고 높이를 제한하지 않는다. 세로형 D2(0.34:1)는 높이가 13.4"까지 늘어나 7.5" 슬라이드를 벗어난다 — ch01 slide 5/10/20에서 실측 확인(하단 15.2"/11.7"/12.9").
2. **HTML(ppt-preview/storyboard/panseo)**: 이미지가 미디어 셀 가장자리에 붙는다(`.ppt-media`·`img`에 padding 없음). 캔버스엔 패딩이 있으나 자산 자체에 여백이 없어 답답하고, 세로형 자산은 셀 높이를 꽉 채운다.
3. **책(Typst)**: `typst_builder`의 auto-image가 페이지 폭에 맞추나, 여백/최대 높이 규칙이 임베드 target별로 통일돼 있지 않다.

## 2. 제안 — 공통 "fit-in-box + 안전 여백" 규약

모든 임베드 target에서 시각자산은 **지정된 박스 안에 종횡비를 유지한 채 들어가고(width·height 둘 다 제한), 박스와 자산 사이에 여백을 남긴다.** 자산이 컨테이너 가장자리에 닿지 않는다.

### A. PPTX (`build_pptx.py`)
- 이미지 배치를 **fit-in-box**로 변경: 이미지 영역 박스(예: 우측 컬럼, 슬라이드 여백 확보)를 정하고, PIL로 이미지 실제 종횡비를 읽어 **width·height 중 박스에 먼저 닿는 쪽**을 기준으로 스케일(종횡비 보존). 박스 안에서 수직·수평 중앙 정렬.
- 슬라이드 가장자리에서 **안전 여백**(예: 상하 0.5", 좌우 0.5")을 남긴다. 세로형이든 가로형이든 슬라이드를 절대 벗어나지 않는다.

### B. HTML (storyboard / ppt-preview / panseo)
- 자산 컨테이너(`.ppt-media`, `.slide-preview`)에 **내부 패딩**(예: 캔버스 짧은 변의 3~5%)을 주어 자산이 셀 가장자리에 닿지 않게 한다.
- 이미지에 `max-width: 100%`, `max-height: 100%`, `object-fit: contain` 유지(이미 있음) — 여기에 패딩이 더해져 여백 확보.

### C. 책 (Typst)
- 이미지 폭을 본문 폭의 일정 비율(예: 85~90%)로 제한하고 중앙 정렬, 위아래 여백 확보. 세로형 이미지는 **최대 높이**(예: 페이지 본문 높이의 70%)로 clamp해 한 페이지를 넘지 않게 한다.

### D. 공통 규약 문서화
- `visual-assets` 또는 공통 참조에 "임베드 안전 여백 규약"을 명시하고, 소비 스킬(storyboard/ppt-preview/panseo/pptx-build/book-build) SKILL.md가 이를 참조한다.
- 여백 비율은 상수로(예: `EMBED_MARGIN_RATIO = 0.05`) 두어 target 간 일관.

## 3. 대안 (기각 후보)
- **자산 생성 단계에서 여백을 구운다**(D2 `--pad`를 크게): 자산 파일 자체에 여백이 박혀 다른 곳에 재사용 시 이중 여백. 임베드 시점에 target별로 여백을 주는 게 유연. 기각 권고.
- **종횡비를 강제로 16:9로 맞춘다**(레터/필러박스 굽기): 자산이 왜곡되거나 불필요한 배경이 생김. object-fit + 패딩이 더 깔끔. 기각 권고.

## 4. 영향 범위 / 되돌리기
- 영향: `scripts/build_pptx.py`(fit-in-box 로직), 소비 스킬 5종 SKILL.md(여백 규약 참조), 소비 HTML 생성 시 CSS 패딩, 책 이미지 사이징. ch01 재생성으로 실증.
- 되돌리기: 각 변경 개별 커밋. build_pptx.py는 이전 width-only 로직으로 revert 가능.

## 5. 검증 기준
- PPTX: 전 슬라이드 이미지가 슬라이드 경계 안(오버플로 0), 가장자리에서 여백 확보.
- HTML: 자산이 셀 가장자리에 닿지 않음(패딩 확인), 세로형도 캔버스 높이 안에 여백과 함께.
- 책: 이미지가 페이지를 넘지 않고 좌우·상하 여백 확보.

# 프롬프터 나레이션 규칙

## 목적

강사가 프롬프터를 읽으며 촬영한다. 문서 문장과 말하기 문장은 다르다 — 나레이션 원고는 **소리 내어 읽었을 때 자연스러워야** 한다.

## 작성 규칙

- 짧은 문장. 구어체 연결("그런데", "자, 이제"). 호흡 단위 줄바꿈.
- 한 문단 = 한 호흡 블록 (슬라이드 1장 또는 화면 전환 1회 분량).
- 전문 용어 첫 등장 시 풀어 말하기를 병기한다.
- 원고에 없는 내용 추가 금지. 축약 시 학습 목표 연결 문장 삭제 금지.

## 큐 마커 (촬영 큐시트의 원천)

화면 전환 지점을 마커로 표기한다:

```text
[SLIDE 07]    ← 슬라이드 전환
[SIM 실행: request-flow.html]
[SIM 종료 → SLIDE 08]
[IDE 화면: 02-controller-added]
[IDE 종료 → SLIDE 12]
```

큐시트는 이 마커를 시간 순으로 추출해 [예상 시각 / 화면 / 행동] 표로 만든 것이다.

## 길이 검증 (필수)

- 환산 기준: **한국어 발화 분당 250~300자** (공백 제외).
- 레슨별로 자수 → 예상 분량을 계산해 `duration_minutes`와 대조한다.
- 허용 오차 ±10%. 초과/미달 시 prompter-script-agent가 임의 조정하지 말고 규모와 조정 후보를 보고한다 (내용 결정권은 원고/사용자).
- 검증 결과 표(레슨 / 자수 / 예상 분 / 계획 분 / 판정)를 `_workspace/`에 남긴다 — G6 체크리스트 항목의 근거.

문제풀기 1

내장 Tomcat이 시작되는 이유로 가장 적절한 것은?

1. 브라우저가 자동으로 Tomcat을 설치한다.
2. Web MVC 스타터와 자동 설정으로 실행 환경을 구성한다.
3. 모든 Java 프로그램은 8080 포트를 연다.
4. Controller가 데이터베이스를 자동 생성한다.

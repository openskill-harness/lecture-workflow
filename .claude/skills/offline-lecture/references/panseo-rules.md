# 오프라인 판서슬라이드 규칙 (summary 프로파일)

이 문서는 **`style.slide_mode: summary`일 때**의 규칙이다. rich 선택 시에는 filmed의 `slide-rules.md`(고밀도·라이트 엔진)를 준용하고 대본은 진행 노트가 담당한다. 생성 방법은 `panseo-slide` 스킬(`.claude/skills/panseo-slide/SKILL.md` — 말미 "하네스 통합 재정의" 우선)을 따른다.

## 본질

판서슬라이드는 **강사의 실시간 설명을 위한 발판**이다. 완성된 설명 문서가 아니다. "슬라이드만 켜서 PPT 읽는 사람"을 만들지 않는 것이 목적이다.

- 화면 글자는 적어야 한다 — 컷당 한 줄 큰 메시지 + (선택) 보조 한 줄. 문장 3줄 이상 금지.
- 강사가 말로 설명하며 판서로 채울 여백이 컷마다 있어야 한다.
- 완성 구조도나 시뮬레이터를 주입해 만드는 산출물이 아니다 — 그것들은 별도 참고 자료일 뿐 필수 입력이 아니다.
- 촬영강의 PPT처럼 밀도 높게 채우는 순간 실패다 (반대 방향 주의: 촬영 슬라이드를 판서슬라이드처럼 비우는 것도 실패).

## G5 승인 대상 (HTML 생성 전)

- 컷 6~9개 구성안 (컷별 한 줄 메시지)
- 중심 비유 1개와 유지 계획
- 부술 오개념 / 심을 진실
- 판서로 채울 내용의 대략 (여백 계획)

## 산출물 검증

- 산출물은 항상 2개: `{이름}_판서보드.html` + `{이름}_판서대본.md`. Registry type: `panseo_slide_html` + `panseo_script`.
- 대본은 컷별 "강렬한 한 줄 → 쉬운 비유 설명 → (개념 매핑 시) 개념 정의". 시간 표기·이모지·연출 지시 금지 (원본 규칙).
- **panseo-board 중복 생성 금지** — Registry에 `panseo_board_html`이 등록되면 qa-agent 자동 blocker.
- 엔진 검증: `node --check`, 컷 수 = `.step` 수, 첫 컷만 `active`.

01

L03 · 책임 경계 흔한 오분류

자주 틀리는 3가지

01

트랜잭션을 웹 계층에 둔다

@Transactional 을 컨트롤러에
서비스 구체 클래스 메서드
02

DTO / Entity 혼용

요청 DTO·영속 Entity 혼용
경계에서 데이터 모양 변환
03

업무 규칙을 형식 검증과 같은 층으로

형식 @NotBlank·@Min = 컨트롤러
업무규칙 "가입?·잔액?" = 서비스
① Spring Reference "Using @Transactional"(서비스 구체 클래스 메서드 권장)  ·  ② Fowler, PoEAA "Data Transfer Object"(프로세스 경계 너머 데이터 운반 — 목적 상이)  ·  ③ 형식/업무 규칙 검증 층 구분
